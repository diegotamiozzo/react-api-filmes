# CineFlix

Projeto web desenvolvido em React com Vite para explorar um catálogo de filmes utilizando a API oficial do TMDb (The Movie Database). A aplicação simula uma plataforma de streaming, permitindo navegar entre páginas de destaque, buscar filmes e visualizar detalhes de produções.

## Funcionalidades

- **Pagina Inicial:** Listagem de filmes populares em formato de grade.
- **Busca de Filmes:** Campo de pesquisa interativo para encontrar títulos em tempo real.
- **Detalhes do Filme:** Página dedicada com sinopse, data de lançamento, avaliações e gêneros.
- **Navegação com Rotas:** Uso de React Router para alternar entre as páginas de forma fluida.

## Tecnologias Utilizadas

- React
- Vite
- React Router DOM
- CSS Estilos Globais
- API do TMDb
